쉘 스크립트 (Shell Script)

쉘 스크립트는 리눅스/유닉스 환경에서 반복적인 작업을 자동화하고, 여러 명령어를 하나의 파일로 묶어 실행하기 위한 프로그래밍 방식입니다. 이 단원에서는 Bash 기초 문법(변수, 조건문, 반복문, 함수)부터 파일 입출력(리다이렉트), 그리고 실무에서 로그 분석에 필수적인 텍스트 가공 명령어(wc, cut, grep, sort, awk, sed 등)까지 학습합니다.

Bash 기초

스크립트 파일 구조

#!/bin/bash
# ==========================
# 파일명: hello.sh
# 설명: 첫 번째 쉘 스크립트
# 작성일: 2026-05-19
# ==========================

echo "Hello, World!"
echo "현재 날짜: $(date +%Y-%m-%d)"
echo "현재 사용자: $USER"
echo "현재 위치: $PWD"
  • Shebang (#!/bin/bash)
    • 첫 줄에 반드시 작성
    • 어떤 인터프리터로 실행할지 지정
  • 실행 권한
    • chmod +x(755) hello.sh
    • ./hello.sh로 실행 (bash hello.sh도 가능)
  • 주석 (#)
    • 실행되지 않음
    • 가독성을 위해 적극 활용

입출력 - echo, read, printf

#!/bin/bash

# ── 출력: echo ──
echo "안녕하세요!"
echo -n "줄바꿈 없이 출력"
echo -e "탭:\t 줄바꿈:\n 완료"      # -e를 사용하면 다양한 이스케이프 시퀀스를 사용할 수 있다

# ── 출력: printf (형식 지정) ──
printf "이름: %-10s 나이: %3d\n" "홍길동" 25
printf "원주율: %.2f\n" 3.14159

# ── 입력: read ──
echo -n "이름을 입력하세요: "
read username
echo "환영합니다, ${username}님!"

# 옵션 활용
read -p "비밀번호: " -s password  # -s: 입력 숨김 / -p: read + echo
read -t 5 -p "5초 내 입력: " answer  # -t: 타임아웃

%f실수

%.2f소수 2자리

read 옵션

  • -p 프롬프트 출력
  • -s 입력 숨김(비밀번호)
  • -t 타임아웃 초 설정
  • -a 배열로 읽기

변수

  • 변수 주요 규칙
    • 공백 불가: name = "홍길동" (X) / name="홍길동" (O)
    • 숫자로 시작 불가: 2name="test" (X) / _name="test" (O)
      • 언더스코어(_)는 사용 가능하다
  • 따옴표
    • 큰따옴표("") 내부에 $ → 치환 변수
    • 작은따옴표('') 내부의 $ → 문자 그 자체로 $ 의미

산술 연산 - (())와 expr

#!/bin/bash

a=10
b=3

# ── 방법 1: $(( )) 권장 ──
echo $((a + b))     # 13
echo $((a - b))     # 7
echo $((a * b))     # 30
echo $((a / b))     # 3  (정수 나눗셈)
echo $((a % b))     # 1  (나머지)
echo $((a ** b))    # 1000 (거듭제곱)

# ── 방법 2: let ──
let result=a+b
echo $result

# ── 방법 3: expr (구형 방식) ──
result=$(expr $a + $b)
echo $result

# ── 증감 연산 ──
((a++))
((b+=5))
echo "a=$a, b=$b"   # a=11, b=8

실습 코드

#!/bin/bash

# ── 기본 if-elif-else ──
read -p "점수를 입력하세요: " score

if [ $score -ge 90 ]; then
    echo "A학점"
elif [ $score -ge 80 ]; then
    echo "B학점"      # ← 이 줄이 출력됨
elif [ $score -ge 70 ]; then
    echo "C학점"
else
    echo "재수강 대상"
fi

# ── [[ ]] 이중 괄호 (Bash 확장) ──
read -p "이름을 입력하세요: " name
if [[ $name == 홍* ]]; then    # 와일드카드 가능!
    echo "홍씨 성입니다"
else
    echo "홍씨가 아닙니다"
fi

논리 연산자 - AND/OR/NOT

#!/bin/bash

age=22
gpa=3.8

# ── AND: -a 또는 && ──
if [ $age -ge 20 ] && [ $gpa -ge 3.5 ]; then
    echo "장학금 신청 가능"
fi

# ── OR: -o 또는 || ──
if [ $age -lt 18 ] || [ $gpa -lt 2.0 ]; then
    echo "자격 미달"
fi

# ── NOT: ! ──
if ! [ -f "/etc/passwd" ]; then
    echo "파일이 없습니다"
fi
  • &&의 경우 앞의 조건이 false이면 뒤의 조건은 아예 실행하지 않음

조건문 - case

  • 고정된 값 또는 패턴으로 분기할 때 (메뉴 선택, 문자열 매칭)
  • *) 전체, [a-z]) 범위, a|b) 복수
#!/bin/bash

read -p "메뉴 선택 (1-4): " choice

case $choice in
    1)
        echo "파일 목록 출력"
        ls -l
        ;;
    2)
        echo "현재 날짜: $(date)"
        ;;
    3|4)         # | 로 여러 패턴 매칭
        echo "옵션 3 또는 4 선택됨"
        ;;
    [a-z])       # 소문자 한 글자
        echo "소문자가 입력되었습니다"
        ;;
    *)           # 기본값 (default)
        echo "잘못된 입력입니다"
        ;;
esac               # case의 역순으로 종료

반복문 - for

# ① 값 목록 순회
for fruit in apple banana cherry; do
    echo "과일: $fruit"
done

# ② 숫자 범위 {시작..끝}
for i in {1..5}; do
    echo "번호: $i"
done

# ③ C언어 스타일
for ((i=1; i<=5; i++)); do
    echo "카운트: $i"
done
# ★ 파일 목록 순회
for file in /var/log/*.log; do
    echo "파일: $file"
    wc -l "$file"
done

# 배열 순회
servers=("web01" "web02" "db01")
for server in "${servers[@]}"; do
    echo "점검: $server"
done

# 명령 출력으로 순회
for user in $(cut -d':' -f1 /etc/passwd); do
    echo "사용자: $user"
done
  • 반복 횟수가 정해져 있을 때 사용

#!/usr/bin/bash

반복문 - while

# 기본 형태
count=1
while [ $count -le 5 ]; do
    echo "카운트: $count"
    ((count++))
done

# ★★ 파일 한 줄씩 읽기 (핵심!)
while IFS= read -r line; do      # 구분자 X == 한줄 읽기
    echo "줄: $line"
done < input.txt

# IFS=',' 로 CSV 한 줄씩
while IFS=',' read -r name ip; do
    echo "$name → $ip"
done < hosts.csv
  • 조건이 참일 때 실행 → 빠져나올 수 있도록 해줘야 함
    • break → 루프 즉시 종료
    • continue → 현재 반복 건너뛰고 다음 반복으로
  • 파일 한 줄씩 읽기(구분자 X)
    • while do-done 명령어 < 읽을 데이터 (꼭 txt 아니어도 됨)
    • 리다이렉트 방향을 잘 보자
    • read -r: 읽어들일 값 내에 특별한 의미가 있는 텍스트가 있을 수도 있는데, 이런 것을 제거해줌

파일 ':'로 나눠서 두 개 변수로 받기

#!/usr/bin/bash

while IFS=':' read -r user ip; do
    echo "--> $user ----> $ip"
done < /etc/passwd

/etc/passwd 파일을 읽어서, uid가 0으로 설정되어 있는 계정만 출력하라. (만약 star라는 계정을 찾는다면, 더 이상 실행하지 말고 종료하라)

추가 조건 코드 (star 계정 발견 시 종료)

#!/usr/bin/bash

echo -e "\n========================"
while IFS=":" read -r user c uid dummy; do
    if [ $uid -eq 0 ]; then
        echo -e "UID가 0인 계정: ${user}"
    else
        # 만약 계정명이 star라면 즉시 종료
        if [ $user == "star" ]; then
            echo -e "\n${user}를 발견했습니다\n프로그램을 종료합니다\n"
            break;
        fi
        continue
    fi
done < /etc/passwd

echo -e "========================\n"

UID 0 계정만 출력하는 기본 버전

#!/usr/bin/bash

echo -e "\n========================"
while IFS=":" read -r user c uid dummy; do
    if [ $uid -eq 0 ]; then
        echo -e "UID가 0인 계정: ${user}"
    else
        continue
    fi
done < /etc/passwd

echo -e "========================\n"

파일 입출력 - 리다이렉트

기호의미예시주의
>표준출력 → 파일 (덮어쓰기)echo 'hello' > out.txt기존 내용 삭제!
>>표준출력 → 파일 (추가)echo 'hi' >> out.txt이어붙이기 ★
<파일 → 표준입력sort < list.txt파일을 입력으로
2>표준에러 → 파일cmd 2> err.log에러만 저장
2>>표준에러 → 파일 (추가)cmd 2>> err.log에러 누적
&>stdout+stderr → 파일cmd &> all.log모든 출력 저장
2>&1stderr를 stdout으로 합침cmd > out.log 2>&1순서 중요!
/dev/null출력 버리기(무시)cmd > /dev/null 2>&1조용히 실행

★ 실무 황금 패턴

  • bash deploy.sh >> deploy.log 2>&1 — 성공+에러 모두 로그
  • cmd > /dev/null 2>&1 — 성공+에러 모두 버리기
  • awk '{print $1}' /var/log/nginx/access.log.1 | sort | uniq -c | sort -r | head -n 5 — 제일 많이 접속한 IP 5개 출력 (보안 실무에서 많이 사용!)

텍스트 가공 - ① 파일 통계 (wc / head / tail)

wc — Word Count

라인 수·단어 수·바이트 수를 카운팅합니다.

# 기본 출력: 라인 / 단어 / 바이트 순
$ wc access.log
  1842  14736  98304 access.log

# 라인 수만
$ wc -l access.log
1842 access.log

# 여러 파일 동시 집계
$ wc -l *.log
  1842 access.log
   305 error.log
  2147 total

# 파이프와 조합: 현재 실행 중인 프로세스 수
$ ps aux | wc -l
옵션설명
-l라인(줄) 수 — 가장 자주 사용
-w단어 수 (공백으로 구분)
-c바이트 수
-m문자 수 (멀티바이트 안전)

head / tail — 파일 미리보기

head — 파일 앞부분

# 앞 5줄만 보기
$ head -n 5 access.log

# 설정파일 빠르게 확인
$ head -n 20 /etc/nginx/nginx.conf
옵션설명
-n N앞에서 N번째 줄까지 출력
-c N앞에서 N바이트까지 출력

tail — 파일 뒷부분 / 실시간

# 마지막 20줄
$ tail -n 20 access.log

# 실시간 로그 모니터링 ★
$ tail -f /var/log/nginx/access.log
# Ctrl+C 로 종료
옵션설명
-n N뒤에서 N번째 줄까지 출력
-f실시간 추가 내용 계속 출력 (follow)
-F-f + 파일 로테이션 시 재열기

💡 조합 팁: head -n 100 big.log | tail -n 10 → 91~100번째 줄 추출

텍스트 가공 - ② cut / tr (단순 가공)

cut — 열(Column) 잘라내기

구분자(Delimiter) 기준으로 원하는 열만 추출합니다.

# /etc/passwd 구조: root:x:0:0:root:/root:/bin/bash
# 사용자명(1열)만 추출
$ cut -d':' -f1 /etc/passwd
root
daemon
bin
...

# 1열과 7열 (이름 + 기본 쉘)
$ cut -d':' -f1,7 /etc/passwd
root:/bin/bash

# CSV에서 두 번째 컬럼
$ cut -d',' -f2 data.csv

# 문자 위치로 자르기 (1~5번째 문자)
$ cut -c1-5 access.log
옵션설명
-d '구분자'구분자 지정 (기본값: Tab)
-f NN번째 필드(열) 추출
-f 1,31번째와 3번째 필드 추출
-f 1-31~3번째 필드 범위 추출
-c N-M문자 위치(바이트)로 자르기

💡 실전 활용: cut -d':' -f1 /etc/passwd → 시스템에 등록된 모든 사용자 ID 목록 확인

tr — 문자 치환(Translate)

  • 문자를 다른 문자로 1:1 치환하거나 삭제
  • 파이프로만 사용 가능 (파일 인수 없음)
# 소문자 → 대문자
$ echo 'hello world' | tr 'a-z' 'A-Z'
HELLO WORLD

# 공백을 줄바꿈으로 (단어를 한 줄씩)
$ echo 'one two three' | tr ' ' '\n'
one
two
three

# 숫자 이외 문자 모두 삭제
$ echo 'abc123def456' | tr -d 'a-z'
123456

# 연속 공백을 하나로 압축
$ echo 'too   many   spaces' | tr -s ' '
too many spaces
옵션설명
-d 'SET'SET에 있는 문자를 삭제(Delete)
-s 'SET'연속 중복 문자를 하나로 압축(Squeeze)
-c 'SET'SET의 보수(Complement) 대상

tr 문자 집합 표기

표기의미
a-z소문자 전체
A-Z대문자 전체
0-9숫자 전체

텍스트 가공 - ③ grep & 정규표현식

grep (Global Regular Expression Print)

패턴으로 줄 필터링 (패턴에 맞는 줄만 골라냄)

$ grep -i 'error' app.log         # 대소문자 무관
$ grep -n 'timeout' server.log    # 줄번호 출력
$ grep -v '#' config.conf         # 주석 제외
$ grep -r 'TODO' ./src/           # 소스 디렉토리 전체 검색
옵션설명
-i대소문자 구분 없이 검색 (ignore case)
-n일치하는 줄 번호 함께 출력
-c일치하는 줄 수 카운트만 출력
-v패턴과 불일치하는 줄 출력 (invert)
-r디렉토리 하위 파일 재귀 검색
-l일치 파일명만 출력 (줄 내용 X)
-E확장 정규표현식 사용 (egrep과 동일)
-o일치하는 부분만 추출

정규표현식 필수 5가지

메타문자의미예시
^시작 (Start of Line)grep '^ERROR' app.log → ERROR로 시작하는 줄만
$끝 (End of Line)grep 'failed$' auth.log → failed로 끝나는 줄만
.임의 문자 1개grep 'a.c' data.txt → abc, a1c, a-c 등
.*아무 문자 0개 이상grep 'error.*timeout' server.log → 두 단어가 같은 줄에
[ ]문자 범위grep '[45]04' access.log → 404 또는 504 에러

확장 정규표현식 (-E)

표기의미
+1개 이상
?0 또는 1개
{n}정확히 n번
(a|b)a 또는 b

텍스트 가공 - ④ sort / uniq (정렬과 통계)

sort: 정렬

옵션설명
-n숫자 기준 정렬 (문자열 X)
-r역순(내림차순) 정렬
-k NN번째 필드 기준
-t '구분자'필드 구분자 지정
-u정렬 + 중복 제거 (uniq 대체)

uniq: 중복 제거 / 카운트

옵션설명
-c중복 횟수를 앞에 출력 ★
-d중복된 줄만 출력
-u중복되지 않은 줄만 출력
-i대소문자 무시

⚠️ uniq는 연속된 중복만 처리! 반드시 sort 후 파이프로 연결

텍스트 가공 - ⑤ awk & sed

awk

  • 열(Column) 기반 데이터 처리
  • 공백(또는 지정 구분자)으로 분리된 데이터에서 원하는 열을 뽑거나 조건 처리

핵심 내장 변수

변수설명
$0현재 줄 전체
$1, $2 …1번째, 2번째 … 필드
NF현재 줄의 필드 수
NR현재 처리 중인 줄 번호
FS입력 구분자 (기본: 공백)
OFS출력 구분자 (기본: 공백)
 
# 기본 패턴: awk '{action}' file
# 3번째 필드만 출력
$ awk '{print $3}' data.txt

# 메모리 사용량(MB) 추출
$ free -m | grep Mem | awk '{print $3}'

# 구분자 지정 (-F)
$ awk -F':' '{print $1, $7}' /etc/passwd
root /bin/bash

# 조건부 출력 (3번째 필드가 500 이상인 줄)
$ awk '$3 >= 500 {print $0}' access.log

# 합계 계산
$ awk '{sum += $3} END {print "합계:", sum}' data.txt

# BEGIN / END 블록
$ awk 'BEGIN{print "시작"} {print} END{print "끝"}' file

sed

  • 스트림 편집기(Stream Editor)
  • 파일을 열지 않고 스크립트로 즉시 내용 치환·삭제·추출
# s 명령: 치환(Substitute) — 형식: s/찾기/바꾸기/플래그

# 첫 번째 Ubuntu → Linux
$ sed 's/Ubuntu/Linux/' file.txt

# 모든 Ubuntu → Linux (g = global)
$ sed 's/Ubuntu/Linux/g' file.txt

# 원본 파일 직접 수정
$ sed -i 's/Ubuntu/Linux/g' file.txt

# 빈 줄 모두 삭제 (d 명령)
$ sed '/^$/d' file.txt

# 주석 줄(# 시작) 제거
$ sed '/^#/d' config.conf

# 특정 줄만 출력 (2~5번째 줄)
$ sed -n '2,5p' file.txt

# 여러 치환 동시 실행
$ sed -e 's/foo/bar/g' -e 's/baz/qux/g' f.txt
옵션설명
-i원본 파일 직접 수정 (in-place) ⚠️
-n자동 출력 억제 (p 명령과 조합)
-e여러 명령 연속 실행
-r / -E확장 정규표현식 사용

⚠️ -i 옵션 주의! 원본 파일이 즉시 덮어쓰기 → 실습 시 반드시 백업 후 사용!

💡 실전 패턴: 설정 파일 배포 시 환경별 값 자동 치환 — sed 's/{{DB_HOST}}/10.0.0.5/g' template.conf

파이프라인 실전 패턴

# 패턴 1: 가장 많이 접속한 IP Top 10
$ awk '{print $1}' access.log \
    | sort \
    | uniq -c \
    | sort -nr \
    | head -10

# 패턴 2: 404 에러 발생 URI 빈도 Top 5
$ grep ' 404 ' access.log \
    | awk '{print $7}' \
    | sort | uniq -c | sort -nr | head -5

# 패턴 3: 하루 중 시간대별 요청 수
$ awk '{print $4}' access.log \
    | cut -d: -f2 \
    | sort | uniq -c | sort -k2 -n

실무 파이프라인

grep ' 404 ' access.log | awk '{print $1}' | sort | uniq -c | sort -nr | head -10

로그 분석의 정석: 필터링 → 필드 추출 → 정렬 → 빈도 집계 → 역순 정렬 → 상위 N개
