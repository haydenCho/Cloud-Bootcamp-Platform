BMI 계산기

  1. 조건
    • 체질량지수(BMI) = 체중(kg) / (신장(m) * 신장(m))
    • 출력문
      이름:   
신장:
체중: 
홍길동의 BMI 지수는 20입니다.
  2. 코드
    # 입력받기
name = input("이름: ")
height = int(input("신장(cm): "))/100  # 신장은 m 단위라 100 나누기
weight = int(input("체중(kg): "))

# BMI 계산
bmi = weight / (height * height)

# 출력
print(f"{name}의 BMI 지수는 {bmi:.2f}입니다.")

기말 평균 학점 구하기

  • 성적표를 참고하여 난생이의 평균 학점을 구해보자
  • 내 코드(그냥 값만)
    #!/usr/bin/python3

# 점수 계산

# 출력

  • 내 코드(딕셔너리)
    #!/usr/bin/python3

# 성적표
scoreDic = {"파이썬":[3, 3.5], "모바일":[2, 4.0], "엑셀":[1, 4.5]}

# 점수 계산
grade = 0
credit = 0
for score in scoreDic.values():
    grade += score[0] * score[1]
    credit += score[0]
avg_grade = grade/credit

# 출력
print(f"평균 학점: {avg_grade:.2f}")

학생 줄 세우기

  • A, B, C, D, E 다섯 명의 학생들에게 도시락을 나눠주려고 합니다. 다섯 명의 학생들이 도시락을 받기 위해 순서대로 줄을 서려면 총 몇 가지의 경우의 수가 나올까요?
  • 이런 경우 팩토리얼 함수를 사용하면 쉽게 해결된다
    • 팩토리얼(Factorial): 1부터 n까지 숫자의 곱을 의미한다.
    • 팩토리얼은 기호로 !를 사용합니다. 예로 5!은 1×2×3×4×5로 계산되어 120이 된다.
  • 내 코드
    #!/usr/bin/python3
COUNT_STUDENT = 5  # 학생 수
result = 1         # 결과

# 경우의 수 계산: 팩토리얼
for i in range(1, COUNT_STUDENT+1):
     result *= i

# 경우의 수 출력
print(f"A, B, C, D, E 학생들을 순서대로 세우는 경우의 수 : {result}")
  • 살짝 수정한 내 코드

    #!/usr/bin/bash

## 함수 정의
# 값 출력하기
def calc(n1, n2, op):
    result = 0
    match op:
        case "+":
            result = n1 + n2
        case "-":
            result = n1 - n2
        case "*":
            result = n1 * n2
        case "/":
            result = n1 / n2
        case _:
            print("잘못된 입력값")
    return result

# 연산자 입력 받기
op = input("계산 입력( +, -, *, / ): ")

# 숫자 입력 받기
num1 = int(input("첫 번째 숫자 입력: "))
num2 = int(input("두 번째 숫자 입력: "))

# 함수 호출
result = calc(num1, num2, op)
