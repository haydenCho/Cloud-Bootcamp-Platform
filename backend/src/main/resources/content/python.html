파이썬 기초 정리

클라우드 부트캠프에서 학습한 파이썬 기초 내용을 정리한 학습 자료입니다. 파이썬 실행 방식부터 자료형과 연산자, 문자열 포매팅, 조건문·반복문·함수·모듈, 컨테이너 자료형, 표준 라이브러리(collections·itertools), 컴프리헨션, 입출력, 예외 처리, 클래스와 객체 지향까지 다룹니다.

파이썬 실행

파이썬을 실행하는 방법은 크게 두 가지입니다.

  1. 대화형 스크립트(인터프리터) — 터미널에서 python3를 입력하면 대화형 셸이 실행되며, >>> 프롬프트에 코드를 한 줄씩 입력해 즉시 결과를 확인할 수 있습니다. 
    $ python3
Python 3.12.3 (main, Mar 23 2026, 19:04:32) [GCC 13.3.0] on linux
Type "help", "copyright", "credits" or "license" for more information.
>>>
>>>
  2. 소스 코드 파일 실행 — 작성한 .py 파일을 python [파일명] 형태로 실행합니다.

파이썬 파일은 별도의 권한 변경(실행 권한 부여) 없이 python 명령으로 바로 실행할 수 있습니다.

파이썬은 인터프리터 언어이므로 실행 파일(바이너리)을 만드는 것이 아니라, 실행 환경에도 언어 해석기(파이썬 인터프리터)가 설치되어 있어야 실행이 가능합니다.

자료형 및 연산자

변수 — 문자열 연산

문자열의 연산은 곱셈(반복)과 문자열끼리의 덧셈(연결)만 가능합니다. 나눗셈·뺄셈, 문자열과 숫자의 덧셈은 모두 TypeError가 발생합니다.

>>> print(str2*3)

>>> print(str2/3)

>>> print(str2-3)

변수명 규칙

  1. 숫자로 시작하거나 숫자로만 이뤄지면 안 됩니다.
  2. 변수명에 언더바(_)를 사용할 수 있습니다. (일부 예약어는 언더바를 2개 사용하기도 합니다.)
  3. 변수명은 대문자와 소문자를 구분합니다.
    • 파이썬은 대문자와 소문자를 완전히 다른 것으로 취급합니다.
    • 따라서 대소문자만 다른 변수명은 서로 다른 변수입니다.
    • 대문자와 소문자를 섞으면 언더바 대신 의미를 부여하기에 좋습니다.
    • 다음은 모두 올바르며, 서로 다른 변수입니다. 
      mynumber = 100
MYNUMBER = 200
Mynumber = 300
myNumber = 400    # 카멜 표기법
my_number = 500   # 스네이크 표기법
MY_NUMBER = 600   # (upper case) 상수 정의
MyNumber = 700    # 파스칼 표기법
  4. 변수명에 예약어를 사용할 수 없습니다.

파이썬의 자료형

  • 파이썬은 C와 달리 데이터의 주소값을 참조하는 것이 아니라, 변수를 위한 메모리 공간을 확보하고 해당 공간에 값을 저장합니다.
  • 타입에 따라 메모리 차지 공간이 다르므로 타입을 잘 써줘야 합니다.
    • 파이썬은 타입을 지정하지 않아도 값에 따라 타입이 결정됩니다(동적 타이핑). 임의로 변경(형변환)도 가능합니다.
    • 정수는 4byte, 실수는 8byte이므로 정수 + 실수의 결과값은 (더 큰) 실수가 됩니다.

기본 자료형

구분설명예시
int정수 (소수점 없음)10, -5, 1_000_000
float실수 (소수점 있음)3.14, -2.5, 1e10
str문자열 (텍스트)"hello", '파이썬'
bool참/거짓True, False
NoneType값이 없음을 표현None

참고로 complex(복소수) 타입도 존재합니다. 예: 1 + 2j

Bool

bool은 int의 하위 타입입니다. True=1, False=0으로 연산이 가능합니다.

비어 있거나 '0', '없음'을 의미하는 값은 모두 False로 처리됩니다.

  • 숫자: 0, 0.0
  • 빈 컨테이너: ""(빈 문자열), [](빈 리스트), ()(빈 튜플), {}(빈 딕셔너리), set()(빈 집합)
  • 빈 값/기타: None, False 자체

타입별 사이즈

sys.getsizeof()로 객체가 차지하는 메모리 크기를 확인할 수 있습니다. 문자열은 길이가 길수록 더 많은 메모리를 사용합니다.

>>> a = "안녕"
>>> sys.getsizeof(a)

>>> a = "안녕하세요"
>>> sys.getsizeof(a)
68
>>> a = 10
>>> sys.getsizeof(a)
28

연산자 예제 — 결과와 자료형 예측하기

아래 표현식의 결과와 자료형을 실행 전에 먼저 예측하고, 직접 실행해 확인해 봅니다.

힌트: /는 항상 float 반환 | //는 int | bool("")는 False | "a"*3은 "aaa"

print(10/2,   type(10/2))    # 5.0 <class 'float'>
print(10//2,  type(10//2))   # 5 <class 'int'>
print(2**3,   type(2**3))    # 8 <class 'int'>
print(10%3,   type(10%3))    # 1 <class 'int'>
print("a"*3,  type("a"*3))   # aaa <class 'str'>
print(True+True, type(True+True))    # 2 <class 'int'>
print(bool(""), type(bool("")))      # False <class 'bool'>
  • 공백(빈 문자열 "")은 False입니다.

문자열 포매팅

문자열 포매팅은 템플릿에 값을 삽입해 새로운 문자열을 만드는 과정입니다. 파이썬은 다음 네 가지 방법을 지원합니다.

1. 연결 연산자 (+)

name = "John"
age = 30
message = "제 이름은 " + name + " 이고, 나이는 " + str(age) + "살입니다."

2. % 연산자

message = "제 이름은 %s이고, 나이는 %d살입니다." % (name, age)

3. str.format()

message = "제 이름은 {}이고, 나이는 {}살입니다.".format(name, age)

4. f-string (권장)

message = f"제 이름은 {name}이고, 나이는 {age}살입니다."

현대적인 파이썬 코드에서는 f-string이 가장 널리 사용됩니다. 가독성이 높고 표현이 간결합니다.

주요 문자열 메서드

  • str.upper() — 모든 문자를 대문자로 변환
  • str.lower() — 모든 문자를 소문자로 변환
  • str.strip() — 앞뒤 공백·탭·개행 제거
  • str.split() — 구분자 기준으로 분리하여 리스트 반환
  • str.join() — 리스트를 구분자로 연결하여 문자열 반환
  • str.replace() — 지정 부분 문자열을 다른 문자열로 대체
  • str.startswith() — 지정 문자열로 시작하면 True
  • str.endswith() — 지정 문자열로 끝나면 True

조건문 (Conditionals)

조건에 따라 다른 코드 블록을 실행하려면 if / elif / else를 사용합니다.

x = 0

if x > 0:
    print("x는 양수입니다")
elif x < 0:
    print("x는 음수입니다")
else:
    print("x는 0입니다")

논리 연산자 and, or, not으로 조건을 조합할 수도 있습니다.

x = 10
if x > 0 and x < 100:
    print("x는 두 자리 양의 정수입니다")

반복문 (Loops)

파이썬에는 for 반복문과 while 반복문 두 종류가 있습니다.

for 반복문

시퀀스(리스트, 문자열 등)의 각 항목을 순회합니다.

fruits = ["apple", "banana", "cherry"]
for fruit in fruits:
    print(fruit)

while 반복문

조건이 참인 동안 반복 실행합니다.

i = 0
while i < 5:
    print(i)
    i += 1

break / continue

break는 반복문을 즉시 종료하고, continue는 현재 반복을 건너뜁니다.

for i in range(10):
    if i == 5:
        break           # i가 5가 되면 반복 종료
    elif i % 2 == 0:
        continue        # 짝수는 건너뜀
    print(i)            # 1, 3 출력

함수 (Function)

함수는 특정 작업을 수행하는 재사용 가능한 코드 블록입니다. def 키워드로 정의합니다.

def greet(name):
    print("안녕하세요, " + name + "님!")

greet("Alice")  # 안녕하세요, Alice님!

매개변수에 기본값(default value)을 지정할 수 있습니다.

def calculate_sum(a, b=0):
    return a + b

print(calculate_sum(5))       # 5
print(calculate_sum(5, 10))   # 15

return 키워드로 값을 반환합니다.

def calculate_product(a, b):
    return a * b

result = calculate_product(3, 4)
print(result)  # 12

모듈 (Module)

모듈은 파이썬 코드를 담은 파일로, import 문을 사용해 다른 스크립트에서 가져와 쓸 수 있습니다.

import math

print(math.sqrt(25))            # 5.0
print(math.sin(math.pi / 2))    # 1.0

from 키워드로 특정 함수나 변수만 가져올 수도 있습니다.

from math import sqrt, pi

print(sqrt(25))  # 5.0
print(pi)        # 3.141592653589793

파이썬 표준 라이브러리에는 파일 I/O, 네트워크, GUI 등 다양한 모듈이 포함되어 있으며, 서드파티 패키지는 PyPI에서 pip를 통해 설치할 수 있습니다.

컨테이너 자료형

list (리스트)

핵심 특성

  • 생성: [ ] 대괄호 사용
  • 인덱스는 0부터 시작, 음수 인덱스 사용 가능 (-1 = 마지막)
  • 값 변경·추가·삭제 가능 (mutable)
  • 서로 다른 자료형 혼합 가능

인덱싱과 슬라이싱 예시:

my_list = [1, 2, 3, "apple", "banana", "cherry"]

print(my_list[0])   # 1
print(my_list[3])   # "apple"
print(my_list[-1])  # "cherry"
print(my_list[1:4]) # [2, 3, "apple"]  (슬라이싱)

주요 메서드

  • .append(x): 끝에 추가
  • .insert(i, x): i 위치에 삽입
  • .remove(x): 값으로 제거
  • .pop(i): 제거 후 반환
  • .sort(): 원본 정렬 (리스트 메서드)
  • .reverse(): 순서를 뒤집음 (원본 변경)
  • sorted(): 새 리스트 반환 (내장 함수)
  • len() max() min() sum(): 기본 통계

tuple (튜플)

핵심 특성

  • 생성: ( ) 소괄호 사용
  • 인덱스는 0부터 시작, 음수 인덱스 사용 가능 (-1 = 마지막)
  • 값 변경 불가 (immutable) — 읽기 전용
  • 리스트보다 메모리 효율적이고 속도가 빠름
  • 요소 1개일 때는 (42,)처럼 쉼표 필수

함수에서 여러 값을 반환할 때 튜플이 자주 활용됩니다.

def get_name_and_age():
    return "John", 30

result = get_name_and_age()
print(result)  # ("John", 30)

주요 메서드

  • .count(x) — x의 개수 반환
  • .index(x) — x의 위치 반환
  • len() min() max() — 기본 통계
  • 언패킹: x, y = (10, 20)

dict (딕셔너리)

핵심 특성

  • 생성: { } 중괄호, 키: 값 형태
  • 키는 변경 불가 타입만 가능 (str, int, tuple)
  • Python 3.7+ 부터 삽입 순서 유지
  • 키 중복 불가, 값 중복 가능

주요 메서드

  • d[k] / d.get(k, 기본값) — 조회
  • d.keys() d.values() d.items()
  • d[k] = v — 추가/수정
  • del d[k] / d.pop(k) — 삭제
  • d.update({...}) — 병합

set (셋)

핵심 특성

  • 생성: { } 중괄호 (빈 set은 set())
  • 중복 자동 제거, 순서 없음
  • 원소는 변경 불가 타입만 가능
  • 수학적 집합 연산 지원

주요 메서드 / 연산자

  • s.add(x) — 원소 추가
  • s.remove(x) / s.discard(x) — 삭제 (remove는 없으면 KeyError, discard는 없어도 오류 없음)
  • s.pop() — 임의 원소를 제거하고 반환
  • s.clear() — 모든 원소 제거
  • s | t 또는 s.union(t) — 합집합
  • s & t 또는 s.intersection(t) — 교집합
  • s - t 또는 s.difference(t) — 차집합
  • s ^ t 또는 s.symmetric_difference(t) — 대칭차집합
  • s <= t — 부분집합 여부

컨테이너 타입 변수는 알아보기 쉽게 뒤에 타입명을 붙이는 것이 좋습니다. 예: fooList, fooDic, fooTup

컨테이너 관련 모듈 · 라이브러리

collections — 강화된 컨테이너

collections.defaultdict — 딕셔너리

  • 존재하지 않는 키에 접근해도 KeyError 없이 기본값을 자동 생성합니다.
  • 생성 시 기본값 타입 지정: list, int, set 등
from collections import defaultdict

# 단어 등장 횟수 세기
count = defaultdict(int)
for w in ["a", "b", "a"]:
    count[w] += 1
# {"a": 2, "b": 1}

# 그룹핑
groups = defaultdict(list)
groups["A"].append("홍길동")

collections.Counter — 카운터

  • iterable의 원소 개수를 자동으로 집계하는 dict 서브클래스입니다.
  • .most_common(n)으로 가장 많은 n개를 반환합니다.
  • Counter끼리 + - & | 연산이 가능합니다.
from collections import Counter

c = Counter("abracadabra")
print(c.most_common(3))
# [('a', 5), ('b', 2), ('r', 2)]

words = ["apple", "banana", "apple"]
print(Counter(words))
# Counter({'apple': 2, 'banana': 1})

collections.deque — 양방향 큐

  • 양방향 큐 — 앞/뒤 모두 O(1)로 삽입·삭제합니다.
  • list의 insert(0, x)는 O(N)이지만 deque는 O(1)입니다.
  • maxlen 지정 시 크기가 고정되어 오래된 것이 자동 삭제됩니다.
from collections import deque

dq = deque([1, 2, 3])
dq.appendleft(0)   # [0, 1, 2, 3]
dq.popleft()       # O(1)

# 최근 N개만 유지
log = deque(maxlen=3)
for i in range(5): log.append(i)
# deque([2, 3, 4], maxlen=3)

collections.namedtuple — 네임드 튜플

  • 필드명이 있는 tuple입니다. 클래스 없이 구조체처럼 사용할 수 있습니다.
  • OrderedDict는 삽입 순서 보장 + 이동 메서드를 추가로 제공합니다.
from collections import namedtuple

Point = namedtuple("Point", ["x", "y"])
p = Point(10, 20)
print(p.x, p.y)   # 10 20
print(p[0])       # 10 (인덱스도 가능)
x, y = p          # 언패킹도 가능

heapq · bisect · array — 성능 특화

heapq

  • list를 최소 힙으로 사용합니다. 가장 작은 값 추출이 O(log N)입니다.
  • nlargest / nsmallest를 제공합니다.
import heapq

h = []
heapq.heappush(h, 3)
heapq.heappush(h, 1)
heapq.heappush(h, 5)
print(heapq.heappop(h))
# 1 (최솟값)

bisect — 이진 탐색

  • 정렬된 리스트에서 이진 탐색합니다. 삽입 위치 탐색이 O(log N)입니다.
  • insort로 정렬을 유지하며 삽입할 수 있습니다.
import bisect

a = [1, 3, 5, 7]
bisect.insort(a, 4)
# [1, 3, 4, 5, 7]

i = bisect.bisect_left(a, 5)
# 5의 위치: 3

array — 배열

  • 단일 타입만 저장하는 배열입니다. list보다 메모리 효율이 높습니다.
  • 타입코드: 'i' 정수, 'f' 실수, 'd' double
from array import array

무한/유한 반복자

  • product(a, b) — 데카르트 곱 (중첩 for문 대체)

컴프리헨션 (Comprehension) — 파이썬다운 코드

문법 구조

  • [표현식 for 변수 in 반복가능객체]
  • [표현식 for 변수 in 반복가능객체 if 조건]
  • 딕셔너리: {k:v for k,v in ...}
  • 집합: {표현식 for ...}
  • 제너레이터: (표현식 for ...)

2중 이상 중첩 컴프리헨션은 가독성이 저하되므로 for문으로 대체하는 것을 권장합니다.

# for문 → 컴프리헨션
squares = [i**2 for i in range(1,6)]
print(squares)    # [1, 4, 9, 16, 25]

# 조건 필터링
evens = [x for x in range(10) if x%2==0]
print(evens)      # [0, 2, 4, 6, 8]

# 딕셔너리 컴프리헨션
words = ["apple", "banana", "cherry"]
wlen = {w:len(w) for w in words}
print(wlen)
# {'apple':5, 'banana':6, 'cherry':6}

# 집합 컴프리헨션 (중복 자동 제거)
uniq = {x%3 for x in range(10)}
print(uniq)       # {0, 1, 2}

코드를 본격적으로 작성하기 전에 의사코드를 미리 작성하는 습관을 들이면 좋습니다. (주석으로 작성하기)

클래스

클래스란

객체를 생성하기 위한 설계도 또는 틀입니다.

  • 객체의 상태를 나타내는 속성(변수/필드)과 객체의 동작을 나타내는 기능(메서드/함수)으로 구성됩니다.
    • 속성(Attributes/Fields): 객체가 가지는 고유한 데이터 (예: 자동차 클래스의 색상, 속도)
    • 메서드(Methods): 객체가 수행할 수 있는 행동 (예: 자동차 클래스의 주행하기, 정지하기)
  • 클래스는 설계도 자체이며, 이 설계도를 바탕으로 메모리에 실제로 생성된 실체를 객체(Object) 또는 인스턴스(Instance)라고 합니다.
    • 클래스: 붕어빵 틀 (개념)
    • 객체(인스턴스): 틀에서 찍어낸 팥 붕어빵, 슈크림 붕어빵 (실제)

파이썬의 클래스

  • 자바 등과 달리 클래스를 사용할 때 클래스 생성을 안 해도 됩니다.
  • 예를 들어 리스트도 클래스인데, 그냥 varList = []와 같이 리스트 인스턴스를 만들면 됩니다. 메서드들도 함께 사용 가능합니다.

객체 지향의 4대 특징

  • 캡슐화(Encapsulation): 관련 있는 데이터와 메서드를 하나의 클래스로 묶고, 외부에서 접근을 제한하여 데이터를 보호하는 것
  • 상속(Inheritance): 기존 클래스(부모)의 특성을 새로운 클래스(자식)가 물려받아 코드의 중복을 줄이는 것
  • 다형성(Polymorphism): 같은 이름의 메서드가 상황에 따라 다른 동작을 하도록 하는 것 (오버라이딩, 오버로딩)
  • 추상화(Abstraction): 복잡한 객체의 핵심적인 특징만 추출하고 불필요한 세부 사항은 숨기는 것

try-except (예외 처리)

예외처리문입니다. 발생 가능한 예외 유형별로 except 블록을 나눠 처리할 수 있습니다.

try:

리스트 — 추가 정리

  • 중복을 제거한 리스트를 사용하고 싶다면, 셋으로 형변환(set())을 한번 하고 다시 리스트로 변환(list())합니다.

튜플 — 추가 정리

  • 튜플은 값을 변경할 수 없지만 아예 재할당은 가능합니다. 
    numTup2 = ('A', 'B')
numTup2 = numTup2 * 2
>> ('A', 'B', 'A', 'B')   # 에러 발생하지 않음
  • 하지만 튜플은 값을 변경하지 않는 것이 중요한 자료구조이므로, 변경하지 않는 방향으로 코드를 작성해야 합니다.
  • 튜플의 내용을 바꿔야 한다면 리스트로 형변환(list())하여 값을 변경한 다음 다시 튜플로 변환(tuple())합니다.

딕셔너리 — 추가 정리

  • 딕셔너리의 키는 중복되지 않고 유일합니다.
    • 동일한 키를 갖는 딕셔너리를 생성해도 오류가 발생하지는 않고, 마지막에 있는 키의 값이 적용되어 생성됩니다.
    • 값은 중복되어도 상관없습니다.

딕셔너리 함수

  • .keys(): 딕셔너리의 모든 키만 뽑아서 반환합니다. 
    >>> empDict.keys()
dict_keys(['사번', '이름', '부서'])
  • list(딕셔너리이름.keys()): 출력 결과에 dict_keys가 붙지 않습니다. 
    >>> list(empDict.keys())
['사번', '이름', '부서']
  • .values(): 딕셔너리의 모든 값을 반환합니다. dict_values가 보기 싫으면 list(딕셔너리이름.values())를 사용합니다. 
    >>> empDict.values()
dict_values([1000, '홍길동', '케이팝'])
  • .items(): (키, 값) 튜플 형태로 구합니다. 
    >>> empDict.items()
dict_items([('사번', 1000), ('이름', '홍길동'), ('부서', '케이팝')])
  • in: 딕셔너리 안에 키가 있는지 확인합니다. 키가 있으면 True, 없으면 False를 반환하며, if문과 함께 자주 사용됩니다. 
    >>> '이름' in empDict
True

>>> '주소' in empDict
False

global

  • 지역변수의 값을 함수 내에서 (전역변수로) 변경할 수 있도록 해주는 예약어입니다.
  • 함수 내에서는 지역변수 > 전역변수 우선순위입니다. 
    def g():
    print(a)

def f():
    a = 10
    print(a)

a = 20

f()
g()

>>> 10
>>> 20
  • 함수 내에서 전역변수의 값을 바꾸고 싶어서 함수 f와 같이 작성하면, 전역변수로 인식하는 게 아니라 지역변수 a를 새로 생성하게 됩니다. 그래서 전역변수의 값이 변경되지 않습니다.
  • 변수 초기화와 값 변경 방식이 같기 때문에 어쩔 수 없는 동작입니다.

global 사용

def g():
    print(a)

def f():
    global a
    a = 10
    print(a)

a = 20

f()
g()

>>> 10
>>> 10
  • 함수 내에서 a라는 변수가 지역변수가 아닌 전역변수 a라는 것을 명시합니다.
  • 값이 제대로 변경되는 것을 확인할 수 있습니다.

예제 코드: __eq__(), __lt__()

__eq__는 ==(같음), __lt__는 <(작음) 연산자의 동작을 정의합니다. __add__와 함께 정의하면 객체끼리 비교하고 연산할 수 있습니다.

#!/usr/bin/python3

class Line():
    length = 0

    def __init__(self, length):
        self.length = length
        print(f"{self.length} 길이의 선이 생성되었습니다. ")

    def __del__(self):
        print(f"{self.length} 길이의 선이 제거되었습니다.")

    def __add__(self, other):
        return self.length + other.length

    def __eq__(self, other):
        return self.length == other.length

    def __lt__(self, other):
        return self.length < other.length
#!/usr/bin/python3
from Line import Line

line1 = Line(10)
line2 = Line(5)

print("두 선의 합: ", line1 + line2)

if line1 < line2:
    print("선 2가 더 깁니다.")
    del(line1)
elif line1 == line2:
    print("두 선의 길이가 같습니다.")
else:
    print("선 1이 더 깁니다.")
    del(line2)
