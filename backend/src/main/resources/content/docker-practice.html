운영체제 백업 및 리스토어
Linux용 Windows 하위 시스템 배포를 관리하기 위한 인수:

    --export <Distro> <FileName> [Options]
        배포를 tar 파일로 내보냅니다.
        파일 이름은 - for stdout 일 수 있습니다.

        옵션:
            --format <Format>
                내보내기 형식을 지정합니다. 지원되는 값: tar, tar.gz, tar.xz, vhd.

    --import <Distro> <InstallLocation> <FileName> [Options]
        지정된 tar 파일을 새 배포로 가져옵니다.
        파일 이름은 - for stdin 일 수 있습니다.

도커 실습 환경 구축

1. 실습 환경 구축

  1. 디렉토리 생성: mkdir /mnt/c/study/docker -p
  2. 파일 생성: touch foo.txt

윈도우와 리눅스(WSL)의 파일들을 공유해서 사용할 수 있다. 하지만 이럴 경우 파일을 읽고 사용할 때 매우매우 느리다. 꼭 필요할 때만 이렇게 쓰고, 평소에는 WSL의 홈 디렉토리에서 작업을 하자

2. 도커 엔진 다운로드

https://docs.docker.com/engine/install/ubuntu/

  1. 이전 버전의 라이브러리 제거
    sudo apt remove $(dpkg --get-selections docker.io docker-compose docker-compose-v2 docker-doc podman-docker containerd runc | cut -f1)
  2. apt 레포지토리 설치
    # Add Docker's official GPG key:
sudo apt update
sudo apt install ca-certificates curl
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc

# Add the repository to Apt sources:
sudo tee /etc/apt/sources.list.d/docker.sources <<EOF
Types: deb
URIs: https://download.docker.com/linux/ubuntu
Suites: $(. /etc/os-release && echo "${UBUNTU_CODENAME:-$VERSION_CODENAME}")
Components: stable
Architectures: $(dpkg --print-architecture)
Signed-By: /etc/apt/keyrings/docker.asc
EOF

sudo apt update
  3. 패키지 다운로드
    sudo apt install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
  4. 확인
    sudo systemctl status docker
sudo systemctl start docker
sudo docker run hello-world
  5. 도커 실행 권한 추가
    # 1. 현재 접속 중인 사용자($USER)를 docker 그룹에 편입 (-aG: append Group)
sudo usermod -aG docker $USER

# 2. 변경된 그룹 권한을 현재 터미널에 즉시 적용 (또는 서버 재부팅/재로그인 필요)
newgrp docker

# 3. sudo 없이 도커 테스트 이미지(hello-world) 실행해보기!
docker run hello-world
💡 "Hello from Docker!" 메시지가 출력되었다면, 성공적으로 도커 엔진 설치 및 권한 부여가 완료된 것입니다!

도커 명령어

컨테이너 생성 및 실행
docker run -d --name <컨테이너 이름> -p [외부 포트]:[내부 포트] <서버>:[버전]

docker run -d --name myWeb3 -p 83:80 nginx:latest
  • latest 버전은 항상 실행 당시 제일 마지막에 나온 버전 ⇒ 내가 배포한 이후 버전이 바뀌면서 문제가 생길 수 있음
    • 항상 특정 버전을 지정해서 쓰는 게 좋다
볼륨 포함 실행
$ docker run --name some-nginx -v /some/content:/usr/share/nginx/html:ro -d nginx
  • -v 옵션: 볼륨 추가
  • 내가 가지고 있는 실제 파일(/some/content)을 도커 내부의 특정 위치(/usr/share/nginx/html)에서 링크하라
